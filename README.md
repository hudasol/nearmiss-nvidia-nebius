# NearMiss

Replay-to-Redesign: a Physical AI safety experimentation platform that turns warehouse
near-misses into reproducible simulation experiments, and checks whether a proposed safety
change still works when the physical conditions change.

Status: under active construction for the Nebius × NVIDIA Global AI Hackathon 2026
(Physical AI track). Setup instructions will be added as each layer lands.
